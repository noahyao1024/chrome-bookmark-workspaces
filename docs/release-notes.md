Initial public release of Bookmark Workspaces.

- Standalone Alfred workflow and Chrome extension with an explicit native-host installer.
- Bookmark aliases, open-tab reuse, local history, app-entry scopes and Work/Personal groups.
- Archive ranking, same-name result context and literal numeric Google search.
- Universal macOS binaries, original icons, synthetic examples and regression tests.
- Optional diagnostics remain a separate, opt-in source installation.

No personal bookmarks, account/workspace rules, browser databases, local installation records or Apple SF Symbols artwork are included.
